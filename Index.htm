Expresiones Regulares en JavaScript

Ejemplos usando diferentes formas de expresiones regulares en javascrip

¿Que son las expresiones regulaes en JavaScript?

Las expresiones regulares (Reguex) son un sistema para buscar, capturar o reemplazar texto utilizando patrones. Estos patrones son utilizados para buscar, identificar, validar, extraer o reemplazar texto que cumple determinadas condiciones que permiten el uso metodos para un texto de una forma relativamente sencilla y abstracta.

Los patrones de estas expresiones son importantes ya que son usados para encontrar coincidencias dentro de cadenas, ayudarte a identificar texto específico o patrones de caracteres, proveyendo una forma poderosa de buscar, reemplazar, y manipular texto.

¿Como se crean estas expresiones?

En JavaScript, las expresiones regulares se crean mediante la notación literal o el constructor RegExp. La forma literal consiste en encerrar el patrón entre barras diagonales (/patrón/), siendo ideal para búsquedas estáticas y directas. Por otro lado, el constructor utiliza la sintaxis new RegExp('patrón') y es la opción perfecta cuando necesitas construir expresiones dinámicamente usando variables en tiempo de ejecución.

Ejemplos usando Expresiones Regulares

A continuacion, se presentan diferentes ejemplos en donde se puede hacer uso de estas expresiones:

Datos personales

Ejemplo 1: Validacion de correo

Se utiliza el metodo test() para comprobar si el correo tiene una estructura valida usando "@" y "."

Expresion usada: /^[^\s@]+@[^\s@]+\.[^\s@]+$/

Ejemplo 2: Validacion de contraseñas

La contraseña debe tener al menos 8 caracteres,una mayuscula, una minuscula y un numero.

Expresion usada: /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}$/

Ejemplo 3: Validar un numero de telefono

Se utiliza el constructor RegExp() para crear una expresion que acepte exactamente 8 digitos.

Expresion usada: new RegExp("^\\d{8}$")

Ejemplo 4: Detector de diptongos

Se utiliza match() para buscar palabras que contengan un diptongo.

Expresion utilizada: /ai|au|ei|eu|oi|ou|ia|ie|io|ua|ue|uo/gi
